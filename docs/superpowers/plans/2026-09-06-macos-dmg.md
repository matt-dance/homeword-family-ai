# macOS DMG + Desktop Supervisor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a signed macOS `.dmg` that installs Homeward so a parent never installs Docker, Ollama, Python, or Node, and the gateway, web UI, Ollama, and mDNS are running after install (chat model still downloads in the existing wizard).

**Architecture:** A Go supervisor inside `Homeward.app` starts bundled Ollama, embedded-CPython gateway, and Next.js standalone on port 43123; a LaunchAgent keeps it at login; the menu bar owns Open/Quit. Gateway gains `HOMEWARD_MANAGED` so the wizard treats Ollama as included without turning on Docker proxy trust.

**Tech Stack:** Go 1.23, `net/http` health checks, launchd, Next.js standalone, uv-embedded CPython 3.12, official Ollama macOS binary, ffmpeg + espeak-ng, `create-dmg` / `hdiutil`, `codesign`, `notarytool`

**Spec:** `docs/superpowers/specs/2026-09-06-native-installers-design.md`

## Global Constraints

- v1 OS is macOS only (arm64 and amd64 DMGs from the same script).
- Do not bundle the ~2 GB chat model; first-run download uses the existing wizard / `POST /api/v1/ollama/bootstrap`.
- Public web port is 43123, not 80. Do not build a privileged port-80 helper.
- Kid URL is `http://homeward.local:43123/chat` until pairing exists. Pairing is out of scope.
- Start at login and stay running (menu-bar tray). One household computer that stays on.
- Keep Docker for contributors. Do not delete Compose. Do not edit family-facing `README.md`.
- Homework camera / `llava:7b` is not pulled automatically.
- Sign and notarize with Apple Developer ID when `HOMEWARD_CODESIGN_IDENTITY` is set. Unsigned local `.app` trees are allowed for iteration.
- `HOMEWARD_MANAGED=true` and `HOMEWARD_DOCKER=false` on native. Never set `HOMEWARD_DOCKER=true` in the supervisor.
- Gateway remains `127.0.0.1:8000`. Ollama remains `127.0.0.1:11434`. Web binds `0.0.0.0:43123`.
- Do not use `~/.ollama`; models go in `~/Library/Application Support/Homeward/ollama`.
- Do not enable App Sandbox.

## Out of scope

Windows `.exe`, Linux `.deb`, pairing, port-80 helpers, auto-update, PyInstaller, bundling Ollama weights, family `README.md` rewrite, dropping Docker.

```typescript
export function advertisedWebPort(locationPort?: string): number {
  const raw =
    locationPort ?? (typeof window === "undefined" ? "" : window.location.port);
  if (!raw || raw === "80") return 80;
  const n = Number(raw);
  return Number.isFinite(n) && n > 0 ? n : 80;
}

export function kidChatUrl(port: number = advertisedWebPort()): string {
  return `${homewardBaseUrl(HOMEWARD_HOSTNAME, port)}/chat`;
}

export function parentLocalUrl(port: number = advertisedWebPort()): string {
  if (port === 80) return "http://localhost";
  return `http://localhost:${port}`;
}
```

**Interfaces:**
- Consumes: `paths.RuntimeDir`, `paths.WebDir`; `env.ChildEnv` result (`[]string`)
- Produces:
  - `children.Spec` with fields `Name string`, `Path string`, `Args []string`, `Env []string`
  - `children.Specs(resourceRoot, dataDir string, childEnv []string) ([]Spec, error)` in order `ollama`, `gateway`, `web`
    - ollama: `Path=resourceRoot+"/runtime/ollama/ollama"`, `Args=["serve"]`
    - gateway: `Path=resourceRoot+"/runtime/python/bin/python"`, `Args=["-m", "uvicorn", "homeward_gateway.main:app", "--host", "127.0.0.1", "--port", "8000"]`
    - web: `Path=resourceRoot+"/runtime/node/bin/node"`, `Args=[resourceRoot+"/web/server.js"]`
  - `adopt.Decision` with `StartOllama bool`, `Reason string`
  - `adopt.Decide(occupied bool, isOllama bool) Decision` — start only when `!occupied`; if `occupied && isOllama`, `StartOllama=false`, `Reason="adopt"`; if `occupied && !isOllama`, `StartOllama=false`, `Reason="blocked"`
  - `adopt.Probe(url string, timeout time.Duration) (occupied bool, isOllama bool)` — HTTP 200 ⇒ occupied+Ollama; connection refused ⇒ neither; any other TCP success ⇒ occupied, not Ollama
  - `health.Checker` interface `{ Get(url string) (status int, err error) }`

```go
const parentURL = "http://127.0.0.1:43123"

func main() {
	openFlag := flag.Bool("open", false, "open the parent UI")
	uninstall := flag.Bool("uninstall", false, "stop Homeward and remove the login item")
	wipe := flag.Bool("wipe-data", false, "with --uninstall, delete Application Support")
	flag.Parse()
	if *wipe && !*uninstall {
		log.Fatal("--wipe-data requires --uninstall")
	}

	}

	}

	resourceRoot := paths.ResourceRoot(exe)
	childEnv := env.ChildEnv(dataDir, paths.PoliciesDir(resourceRoot), resourceRoot)
	marker := dataDir + "/.browser_opened"

	if *uninstall {
		runUninstall(home, dataDir, *wipe)
		return
	}

	if _, err := launchd.WritePlist(home, exe); err != nil {
		log.Printf("login item plist: %v", err)
	} else if err := launchd.Bootstrap(launchd.PlistPath(home)); err != nil {
		log.Printf("launchctl bootstrap: %v", err)

		log.Fatal(err)
	}

	specs, err := children.Specs(resourceRoot, dataDir, childEnv)
	if err != nil {
		log.Fatal(err)
	}
	occupied, isOllama := adopt.Probe("http://127.0.0.1:11434/api/tags", 300*time.Millisecond)
	decision := adopt.Decide(occupied, isOllama)
	if decision.Reason == "blocked" {
		log.Print("port 11434 is in use by a non-Ollama process")
	}

	manager := proc.New()
	if err := manager.Start(specs, decision.StartOllama); err != nil {
		log.Fatal(err)
	}

	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
	defer cancel()
	check := health.HTTPChecker{}
	if decision.Reason != "blocked" {
		_ = health.Wait(ctx, check, "http://127.0.0.1:11434/api/tags")
	}
	if err := health.Wait(ctx, check, "http://127.0.0.1:8000/api/v1/health"); err != nil {
		log.Printf("gateway health: %v", err)
	}
	if err := health.Wait(ctx, check, parentURL+"/"); err != nil {
		log.Printf("web health: %v", err)
	}

	if *openFlag || browser.ShouldOpenOnBoot(marker) {
		if err := browser.OpenURL(parentURL).Start(); err != nil {
			log.Printf("open browser: %v", err)
		} else if err := browser.MarkOpened(marker); err != nil {
			log.Printf("browser marker: %v", err)
		}

			log.Fatal(err)
		}
	} else {

}
```

- [ ] **Step 3: Implement `dmg-macos.sh`**

Behavior:

1. Usage: `dmg-macos.sh [arm64|amd64] [--sign]`. `--help` prints `Homeward-macos-<arch>.dmg` and exits 0.
2. Runs `bundle-macos.sh` for that arch unless `HOMEWARD_DMG_SKIP_BUNDLE=1`.
3. If `--sign`:
   - Require `HOMEWARD_CODESIGN_IDENTITY` and `HOMEWARD_NOTARY_PROFILE` (exit 2 with a message if missing).
   - `codesign --deep --force --options runtime --entitlements desktop/pack/homeward.entitlements --sign "$HOMEWARD_CODESIGN_IDENTITY" "$APP"`
   - `codesign --verify --verbose=2 "$APP"`
4. Create a read-only DMG with a `/Applications` symlink (use `hdiutil create` + a staging folder, or `create-dmg` if installed). Output `dist/macos/Homeward-macos-$ARCH.dmg`.
5. If `--sign`: `xcrun notarytool submit "$DMG" --keychain-profile "$HOMEWARD_NOTARY_PROFILE" --wait` then `xcrun stapler staple "$DMG"`.
6. Never embed Ollama model weights. Never bind or document port 80.

Add a “SmartScreen does not apply on macOS” note is unnecessary. Add a README troubleshooting section: Gatekeeper block on unsigned local builds is expected; use `--sign` for family machines.
